# 12-14 Haftalık İş Planı (Work Plan)

Proje, akademik takvime uygun olarak 3 ana faza (Planlama, Geliştirme, Raporlama) ayrılmıştır.

## Faz 1: Planlama ve Araştırma (Hafta 1-3)
*   **Hafta 1:** Konu netleştirme, literatür taraması (Tarım 4.0, akıllı tarım uygulamaları).
*   **Hafta 2:** Gereksinim analizi, proje kapsamının (scope) dondurulması. GitHub repo kurulumu.
*   **Hafta 3:** Sistem tasarımı, mimari diyagramlar, API seçimi ve test edilmesi.

## Faz 2: Geliştirme (Hafta 4-10)
*   **Hafta 4:** **Frontend Başlangıç:** React projesinin kurulumu, shadcn/ui entegrasyonu, temel sayfalar (Layout).
*   **Hafta 5:** **Backend Başlangıç:** Node.js/Express kurulumu, Weather Service entegrasyonu (API'den veri çekme).
*   **Hafta 6:** **Data & Dashboard:** Verilerin ön yüze bağlanması, 3 günlük hava kartlarının tasarımı ve kodlanması.
*   **Hafta 7:** **Karar Motoru (Decision Engine):** Don, ekim, sulama kurallarının kodlanması ve birim testleri.
*   **Hafta 8:** **Chatbot (Backend):** Niyet (Intent) analiz yapısının kurulması, kural motoruyla bağlantı.
*   **Hafta 9:** **Chatbot (Frontend):** Sohbet arayüzünün (Chat UI) kodlanması, mesajlaşma akışı.
*   **Hafta 10:** **Entegrasyon ve İyileştirme:** Tüm modüllerin birleşimi, hata ayıklama, frontend makyajı (CSS/Styling).

## Faz 3: Test, Demo ve Raporlama (Hafta 11-14)
*   **Hafta 11:** **Test:** Sistemin farklı şehirler ve senaryolarla test edilmesi (Validation).
*   **Hafta 12:** **Dokümantasyon:** Proje raporunun yazılması (Giriş, Yöntem, Bulgular).
*   **Hafta 13:** **Demo Hazırlığı:** Sunum materyalleri, demo senaryolarının provası, olası risklerin (B planı) gözden geçirilmesi.
*   **Hafta 14:** **Final Teslim ve Sunum.**
